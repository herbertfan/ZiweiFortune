## 2. 頁面結構與導航

### 2.1 全局導航架構

```
┌─────────────────────────────────────┐
│  Tab Bar（底部固定）                  │
│  [命盤]  [幫助]  [關於]  [設定]      │
└─────────────────────────────────────┘
```

- **命盤**：主功能頁（命例列表 → 排盤結果）
- **幫助**：輔助說明
- **關於**：應用資訊
- **設定**：偏好設定

### 2.2 頁面流轉圖

```
[命例列表頁]
    │ 點擊「排盤」或選擇命例
    ▼
[載入中] ── 旋轉 Spinner + 漸進式星曜渲染
    │
    ▼
[命盤主頁] ── 4×3 宮格 + 中央資訊面板
    │
    ├── 點擊底部 Tab（飛星/三合/四化）→ 即時疊加層切換
    ├── 滑動大限/流年/流月/流日/流時 → 即時重算與高亮
    └── 點擊「設定」→ 設定頁（Modal Push）
```

## 7. 動畫與轉場

### 7.1 頁面轉場

| 轉場 | 類型 | 時序 | 細節 |
|------|------|------|------|
| 命例列表 → 命盤 | Push（右入）| 0.3s | 標準 Navigation Push，帶陰影 |
| 命盤 → 設定 | Modal（下上）| 0.3s | 從底部彈出，帶遮罩 |
| 返回 | Pop（左出）| 0.3s | 標準 Navigation Pop |

### 7.2 載入動畫（命盤生成）

```
Phase 1（0.0s - 0.5s）：全屏遮罩 + 旋轉 Spinner
    └── Spinner：白色，中心旋轉，速度 1r/s

Phase 2（0.5s - 1.0s）：宮格線條繪製
    └── 4×3 網格線從左上到右下依序淡入
    └── 淡入時長：每條 0.1s，間隔 0.02s

Phase 3（1.0s - 2.0s）：中央面板資訊填充
    └── 文字從上至下逐行顯示
    └── 每行延遲 0.05s

Phase 4（2.0s - 3.5s）：星曜漸進渲染
    └── 主星先出現（從命宮開始順時針）
    └── 每宮延遲 0.1s
    └── 輔星隨後出現（同宮延遲 0.05s）
    └── 雜曜最後出現

Phase 5（3.5s）：飛星線條繪製
    └── 虛線箭頭一次性淡入（0.3s）
```

### 7.3 微交互

| 場景 | 動畫 | 時序 |
|------|------|------|
| 列表列選中 | 背景色瞬間變淡紫（無漸變）| 0s |
| Tab 切換 | 指示線彈簧滑動 | 0.25s，damping: 0.7 |
| 運限選項點擊 | 文字變色 + 底部線條滑入 | 0.15s |
| 星曜四化標記 | 從右側滑入 + 淡入 | 0.2s |
| 搜尋欄聚焦 | 邊框變藍 + 陰影擴散 | 0.2s |
| 按鈕點擊 | 透明度降至 0.7 後恢復 | 0.1s |
| 載入 Spinner | 連續旋轉（360°/s）| 無限循環 |

## 8. 微互動與狀態

### 8.1 Loading 狀態

- **觸發時機**：點擊「排盤」、切換命例、修改出生資訊後確認
- **視覺表現**：
  - 全屏半透明黑色遮罩（opacity: 0.3）
  - 中心白色圓形背景（80×80pt）
  - 內部系統風格 ActivityIndicator（白色）
- **文字提示**：無文字，僅 Spinner
- **取消方式**：不可取消，需等待完成

### 8.2 按鈕回饋

| 按鈕類型 | 正常態 | 按下態 | 禁用態 |
|----------|--------|--------|--------|
| 主要按鈕（排盤）| 藍底白字 | 透明度 70% | 灰底灰字 |
| 次要按鈕（新增）| 白底綠字 | 背景變淺綠 | 灰底灰字 |
| 危險按鈕（刪除）| 白底紅字 | 背景變淺紅 | 灰底灰字 |
| Tab 按鈕 | 白底灰字 | 文字變深 | 無禁用態 |

### 8.3 空狀態

- **無命例時**：表格區域空白，無提示文字
- **搜尋無結果**：表格空白，無「無結果」提示
- **無網路時**：未在影片中展示（可能為本地應用）

## 12. 可借鑑的 UX 亮點
